MediMap MM

Multimodal emergency diagnostics by Mohammad Irfan Sirkar. It reads the patient's symptom note and their X-ray or CT together, suggests a triage level, and lets the doctor ask follow-up questions. Built for Expogenix 2025.

How the real system works
1. Two inputs
A free-text symptom note plus a chest X-ray or CT image from the emergency room.
2. One model
BiMediX2, a medical vision-language model, reads both together with PyTorch and Transformers on CUDA.
3. Triage
It returns findings, each tagged with whether it came from the text or the image, plus an urgency level.
4. Chat
Doctors ask follow-up questions in the same session, and the model keeps the case in context.
